## What I've built

- **[PulseDB](https://github.com/FionnHughes/PulseDB)**: a self-hosted system monitor. C++2 with its own compressed time-series storage format (about 6 bytes per reading, crash-safe write log), a REST/WebSocket API and a Tauri + React desktop app. v1.0.0 shipped on Windows, and I'm currently porting to Linux.
- **[Irish Open Datasets](https://github.com/FionnHughes/irish-open-datasets)**: a Python data pipeline that scrapes, cleans and publishes Irish and EU public datasets (about 2.3M rows) to Kaggle and Hugging Face on a schedule using GitHub Actions.
- **[Activepieces](https://github.com/activepieces/activepieces/pull/13018)**: merged a Chess.com integration into this open-source workflow automation platform.
